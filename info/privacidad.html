Política de privacidad

Étoile · Última actualización: octubre de 2026

Étoile es una herramienta interna de análisis de reseñas para uso operativo de un grupo restaurantero. No es un servicio abierto al público: solo acceden las personas con una cuenta creada por el administrador.

Qué datos de Google usamos

La aplicación se conecta a la API de Google Business Profile con el permiso https://www.googleapis.com/auth/business.manage, otorgado por el administrador de las fichas del negocio. Con él lee, de las sucursales que ese administrador gestiona:

  • reseñas (calificación, comentario, fecha, nombre público y foto de perfil del reseñador tal como Google los muestra);
  • las respuestas publicadas por el negocio;
  • el nombre y los identificadores de las fichas.

No lee datos de Gmail, Drive, contactos ni de ninguna otra cuenta o servicio de Google.

Para qué los usamos

Únicamente para mostrar calificaciones, tendencias y quejas por sucursal a quienes operan el negocio, y para clasificar las quejas por tema (servicio, calidad, valor). No se usan para publicidad, perfilado, venta ni entrenamiento de modelos de inteligencia artificial.

Dónde se guardan y quién los ve

  • Los datos se almacenan en una base de datos (Supabase) con control de acceso por rol: cada usuario ve solo las sucursales que le corresponden, y no hay lectura anónima.
  • Las credenciales de acceso a Google se guardan como variables de entorno cifradas del servidor y nunca se incluyen en el código ni se envían al navegador.
  • No vendemos, alquilamos ni compartimos estos datos con terceros, salvo los proveedores de infraestructura necesarios para operar el servicio (alojamiento y base de datos).

Uso limitado de datos de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se apegan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Conservación, revocación y eliminación

Las reseñas se conservan mientras la ficha del negocio esté activa en el sistema. El administrador puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions; al hacerlo, la sincronización se detiene. Para solicitar la eliminación de datos o resolver dudas, escribe al contacto indicado abajo.
